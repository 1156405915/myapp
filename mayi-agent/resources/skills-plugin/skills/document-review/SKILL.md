# 文档审查

1. 确认审查目标、适用规则和风险容忍度；没有专业规则时只做通用质量审查。
2. 调用对应格式 Skill 读取全部正文、表格、页眉页脚、批注和可见修订。
3. 依次检查完整性、结构、逻辑、一致性、数字、日期、术语、引用、重复和格式。
4. 每个问题必须包含位置、原文证据、问题说明、严重程度和建议；不得只给笼统评价。
5. 专业合规结论必须有用户提供或可靠来源支持；缺少标准时标记为待专业复核。
6. 将确定错误、潜在风险和优化建议分开，不要把写作偏好当作错误。
7. 对修改后的文件再次执行审查，确认问题是否关闭且没有引入新问题。
8. 按 [references/output-format.md](references/output-format.md) 输出审查结论和问题台账。
