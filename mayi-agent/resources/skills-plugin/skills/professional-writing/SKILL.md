# 专业写作

1. 明确文种、受众、目的、语气、篇幅和必须覆盖的材料。
2. 先提取事实、数据、约束和结论，再设计结构；不得先写结论后寻找材料支撑。
3. 采用正式、清晰、可执行的中文，避免空泛口号、重复表达和无依据的绝对化措辞。
4. 保留用户提供的专有名词、数字、日期和责任主体，不擅自改动事实。
5. 对缺失内容使用占位标记或待确认清单，不编造单位名称、政策依据或项目数据。
6. 章节应服务于文种目标，段落围绕单一主题展开，标题层级保持一致。
7. 按 [references/output-format.md](references/output-format.md) 完成内容自检。
8. 用户要求正式文件时，将定稿内容交给对应格式 Skill 排版、生成并执行质量检查。
