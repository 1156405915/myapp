# 蚂蚁（Mayi Agent）

面向企业知识工作与自动化协作场景打造的智能桌面 Agent，提供安全的本地文件操作、工具执行、专业文档处理和可扩展能力体系。

## 已完成

- 企业级登录页：账号登录、验证码登录、第三方登录交互占位。
- Electron 主进程与安全 Preload 桥接。
- Vue Router 路由守卫与 Pinia 登录状态。
- DeepSeek Anthropic 兼容接口和 Claude Agent SDK 流式执行。
- 会话创建、恢复、排队、取消、删除和消息持久化。
- `Read`、`Glob`、`Grep`、`Write`、`Edit`、`Bash`、Web 和 Skill 工具。
- 工具权限弹窗、单次授权、本会话授权、高风险二次确认和超时拒绝。
- 安全 Markdown 渲染、表格展示、消息复制和外部链接隔离窗口。
- PDF、DOCX、PPTX、XLSX 内置文档技能及构建资源检查。
- 固定底部账号信息和独立滚动的最近会话列表。
- 页面框架：聊天、任务、MCP 工具、技能和文件库。
- 自研蚂蚁 SVG Logo、设计令牌、响应式布局。
- Windows NSIS 打包配置。
