# 施组一致性规则

## 必须一致

- 项目名称、标段、地点、工期、开竣工日期、质量和安全目标。
- 工程范围、主要工程量、材料规格、结构形式和关键技术参数。
- 正文、WBS、横道图、网络图、里程碑和赶工措施。
- 施工阶段、劳动力峰值、班组数量、机械数量和材料进场时间。
- 施工分区、总平面图、临时道路、加工场、堆场、临水临电和消防布置。
- 重难点、危大工程清单、专项方案、监测预警和应急措施。
- 目录、正文标题、图号、表号及交叉引用。

## 检查原则

1. 以 `project-facts.json` 和 `construction-plan.json` 为权威数据源。
2. 无依据的确定值标记为假设，不得混入招标事实。
3. 同一数据出现多个版本时列出全部位置，不以“可能一致”判定通过。
4. 图表必须从同一数据源生成；图片无法读取时标记“未验证”，不得只检查正文。
5. 暗标项目同时检查正文、页眉页脚、文件属性、图片、水印、二维码和附件名称。
