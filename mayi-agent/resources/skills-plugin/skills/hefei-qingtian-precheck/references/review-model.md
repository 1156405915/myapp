# 合肥青天适配预审模型

本模型是 Mayi 的投标前质量检查框架，不是合肥公共资源交易青天大模型的内部算法、提示词或官方评分公式。

## 检查维度

1. **评审适用性**：招标文件是否明示AI辅助评审，最终版本和补疑是否改变相关要求。
2. **否决与格式风险**：否决条款、签章、页数、文件格式、暗标和身份泄露风险是否逐项关闭。
3. **评分覆盖**：每个评分项是否有明确章节、措施、数据、图表或记录证据，追踪表是否无遗漏。
4. **项目针对性**：内容是否来自本项目地点、范围、工程量、现场条件和专业接口，是否残留其他项目痕迹。
5. **可执行与量化**：措施是否说明责任、资源、步骤、参数、频次、验收和异常处置，推算是否有依据。
6. **全局一致性**：正文、图表、计划、劳动力、机械、材料、工期和里程碑是否使用同一数据源。
7. **专业与规范**：专业方法是否适用，规范名称、编号、版本、适用地区和强制性要求是否可靠。
8. **重难点与危大工程**：是否基于项目识别并形成专项方案、监测、预警、应急和验收闭环。
9. **原创和雷同风险**：模板化重复、网络化套话、异常相同图片和可疑错字是否得到处理；只对可合法访问语料给出结论。
10. **成品可读性**：目录、标题、图表、分页、字体、裁切、乱码、空白页和交叉引用是否通过实际渲染检查。

## 风险等级

- `blocking`：招标文件明示可能导致否决、不得分或无法提交的问题，或关键资料缺失导致无法判断。
- `high`：评分项缺失、核心事实冲突、暗标泄露、其他项目残留、关键规范错误或图文数据矛盾。
- `medium`：措施缺少量化、证据不足、一般引用错误、部分图表未验证或存在明显模板化表达。
- `low`：不影响实质响应但会降低可读性、定位效率或专业表达质量的问题。

只有 `blocking` 和 `high` 均为零，且所有评分项都有响应证据时，才能标记“预审就绪”。
