# 资料综合

1. 明确研究问题、范围、时间边界、地区和需要支持的决策。
2. 建立来源清单，记录标题、日期、主体、来源类型和适用范围。
3. 分别提取每个来源的核心观点、证据、限制和结论，避免过早合并。
4. 按主题综合共识、差异、冲突和证据空白，而不是逐篇重复摘要。
5. 优先采用原始、官方和时间匹配的来源；来源质量不同必须明确说明。
6. 事实、来源观点和综合判断分层表达；没有足够证据时不得给出确定结论。
7. 对可能已过时的信息注明日期，并在允许联网时优先核验最新官方来源。
8. 按 [references/output-format.md](references/output-format.md) 输出研究结论和证据矩阵。
