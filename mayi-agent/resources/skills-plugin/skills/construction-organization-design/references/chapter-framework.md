# 章节组织参考

本框架只用于规划，不得覆盖招标文件的评分顺序。优先把评分项映射为可检索的一级或二级标题。

1. 编制依据与项目总体理解
2. 项目组织机构与职责
3. 施工总体部署、分区和流程
4. 施工准备与现场调查
5. 主要分部分项工程施工方法
6. 项目重点难点及针对性措施
7. 危大工程辨识与专项管理
8. 进度计划、关键线路与工期保证
9. 劳动力、机械、材料和资金使用计划
10. 质量管理与试验检测
11. 安全生产与应急管理
12. 文明施工、环境保护和绿色施工
13. 季节性施工及特殊条件措施
14. 施工总平面布置和临时用地
15. 信息化、技术创新及合理化建议
16. 竣工验收、资料移交和保修

项目未包含的专业不得为了完整目录强行加入；招标文件另有命名、顺序或篇幅要求时完全按招标文件调整。
