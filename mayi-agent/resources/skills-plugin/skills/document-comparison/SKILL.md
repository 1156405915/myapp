# 文档对比

1. 确认基准版本和目标版本；无法判断时使用文件时间或用户提供顺序，并明确说明。
2. 调用对应格式 Skill 提取正文、表格、批注和修订信息。
3. 先按标题、条款、页码、表格或工作表对齐，再比较内容，不能只做无结构文本差异。
4. 分别识别新增、删除、修改、位置移动和仅格式变化。
5. 对金额、比例、日期、数量、期限和责任主体进行单独校核。
6. 说明变化可能造成的影响，但将原文事实与分析判断分开。
7. 无法可靠对齐的内容必须标为“待人工确认”，不得强行配对。
8. 按 [references/output-format.md](references/output-format.md) 输出重要差异和完整差异清单。
